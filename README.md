# EK Labs

Website til EK Tema 9. Siden samler EK's seks labs ét sted med Tech & Story Lab i midten, en quiz ("Hvilket lab er du?"), pakker, lån i 3 trin, workshops og AI-guiden Fafi.

**Lavet af:** Mostaffa (Moab1000)

## Sider

- `index.html` – EK Labs-forsiden med orbit, quiz, de seks labs og Fafi
- `tech_story_lab.html` – Tech & Story Lab med pakker, 3 trin, workshops og om labbet
- `lab.html` – skabelon til de fem andre labs, fx `lab.html?id=maker`, `?id=media`, `?id=circular_material`, `?id=circular`, `?id=lab16`

## Filer

- `general.css` – farver og tokens som CSS-variabler, fonte, knapper og tags
- `layout.css` – header, sektioner, grids, orbit, kort, quiz, chat, footer og media queries
- `script.js` – burger-menu, åbent/lukket, peek-kort, quiz, pakker, workshops og Fafi-chat
- `fafi.js` – Fafi-tegningen som SVG-tekst
- `imgs/` – billeder, EK-logo, lab-logoer og Fafi som SVG

## Sådan åbner du siden

Åbn `index.html` i en browser. Der skal ikke installeres noget – siden er ren HTML, CSS og JavaScript uden frameworks.

Design og prototype er lavet i Figma. Fonte: Encode Sans, Encode Sans Condensed og Zilla Slab (Google Fonts).
